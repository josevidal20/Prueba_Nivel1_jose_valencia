# Prueba técnica - Analista de Soporte Nivel 1

Este proyecto se realizó como parte de la prueba técnica para el cargo de Analista de Soporte Nivel 1.

La aplicación permite seleccionar un país y consultar las ciudades que pertenecen a él, mostrando información como el nombre de cada ciudad y su población. Para realizar las consultas se utilizó una base de datos llamada `world`.

## Herramientas utilizadas

Para desarrollar y probar el proyecto se utilizaron las siguientes herramientas:

- **PHP y Laravel:** para construir la aplicación.
- **MySQL:** para guardar y consultar la información de los países y las ciudades.
- **XAMPP:** para ejecutar MySQL de forma local.
- **JavaScript y AJAX:** para consultar la información y actualizar los resultados en la página sin tener que recargarla completamente.

## ¿Cómo funciona la aplicación?

Al ingresar a la aplicación, el usuario puede seleccionar un país y consultar las ciudades relacionadas con él. También puede ver la población de las ciudades y, según las funciones implementadas, identificar las ciudades más y menos pobladas.

La información se obtiene de la base de datos `world`, que contiene datos de países, ciudades e idiomas.


## ¿Cómo ejecutar el proyecto?

1. Instalar PHP, Composer, MySQL y las herramientas necesarias para ejecutar Laravel.
2. Descargar o clonar el repositorio del proyecto.
3. Instalar las dependencias del proyecto con Composer.
4. Importar la base de datos `world` en MySQL.
5. Configurar la conexión a la base de datos en el archivo `.env`.
6. Ejecutar el servidor local de Laravel y abrir la dirección que aparece en la terminal.
